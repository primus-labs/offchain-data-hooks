# CEX Trading Hooks For Uniswap v4

## Overview

This repository introduces a CEX trading hook for Uniswap v4, enabling users to validate their 30-day spot trading volume across centralized exchanges (CEXs) to become eligible for a swap fee discount. Specifically, if a user generates and submits a proof (attestation) of their 30-day CEX trading volume exceeding a specified USDT threshold to the UniChain, and this proof is successfully verified by the hook contract, the user will enjoy a 50% discount on swapping fees on any specified Uniswap pool for a period of 7 days.

As a pool initiator, you can invoke this hook into your own pool on Uniswap v4, to capture high-quality trading users and relevant trading volume from centralized exchanges. Once the hook is bound to a designated pool (token pair), end users will find an external link to create a zkTLS proof. This link directs them through the data verification process using the [Primus zkTLS technique](https://docs.primuslabs.xyz/data-verification/tech-intro). Meanwhile, all sensitive information related to the generated proof—including total trading volume and account details—remains entirely confidential. Neither Primus nor the pool initiator will have access to this private data at any point during the process.

## For Developers

### Prerequisite

Install foundry, see https://book.getfoundry.sh/getting-started/installation.

### Install

Get the repo:

```sh
git clone --recursive https://github.com/primus-labs/offchain-data-hooks.git
cd offchain-data-hooks
forge install
forge build
```

### Primus AttestationRegistry

This contract records the proofs (attestations) generated by users about their 30-day CEX spot trading volume, using the Primus zkTLS technique.

The [AttestationRegistry](src/attestation/AttestationRegistry.sol) contract verifies attestations through the Primus zkTLS contract and stores each recipient's attested trading-volume threshold.

### ExchangeVolumeHook

This is the specific Hook for pools that checks for the trading history from CEX users.

The [ExchangeVolumeHook](src/hook/volume/ExchangeVolumeHook.sol) implements the `afterInitialize` and `beforeSwap` hooks.

### Test Guide

Run the local contract tests with `forge test`.

The walkthrough below deploys test contracts and interacts with a Uniswap v4 pool. The commands assume a Bash-compatible shell and broadcast transactions to the network selected by `RPC_URL`.

### Configurations

Copy the environment template and fill in the settings for your test network:

```sh
cp .env.example .env
```

Alternatively, start from `.env.sepolia` or `.env.unichain-sepolia` and verify the supplied deployment addresses for your chosen network.

| Variable | Used for |
| --- | --- |
| `RPC_URL` | RPC endpoint for the selected test network. |
| `PRIVATE_KEY` | Transaction signer, funded with native tokens for gas and test tokens for liquidity and swaps. |
| `POOL_MANAGER`, `POSITION_MANAGER`, `UNIVERSAL_ROUTER` | Uniswap v4 deployments on the same network; see [deployment addresses](https://docs.uniswap.org/contracts/v4/deployments). |
| `PRIMUS_ZKTLS` | Primus zkTLS verifier contract on the same network, required to deploy the registry. |
| `CONTRACT_OWNER` | Owner of the deployed hook. |
| `FEE_RECIPIENT` | Recipient of attestation submission fees and of the liquidity position minted by the liquidity script. |
| `TOKEN0`, `TOKEN1` | Sorted token addresses printed by the token deployment script. |
| `ATTESTATION_REGISTRY` | Registry address printed by its deployment script; save it before deploying the hook. |
| `HOOK` | Hook address printed by its deployment script; save it before initializing the pool. |

Set the network and account settings first. Fill in the token, registry, and hook addresses as you complete each deployment below. Reload `.env` after saving each change.


### Deployment

Deploy the test token and the test Hook contract.

- Deploy Token


```sh
source .env
forge script script/DeployToken.s.sol:DeployTokenScript --rpc-url "$RPC_URL" --private-key "$PRIVATE_KEY" --broadcast
```

output (sample):

```log
TOKEN0=<deployed token0 address>
TOKEN1=<deployed token1 address>
```

Save both addresses in `.env`, preserving the printed `TOKEN0`/`TOKEN1` order.

<br/>

- Deploy AttestationRegistry

```sh
source .env
forge script script/attestation/AttestationRegistry.s.sol:DeployAttestationRegistry --rpc-url "$RPC_URL" --private-key "$PRIVATE_KEY" --broadcast
```

output (sample):

```log
AttestationRegistry deployed at: <deployed registry address>
```

Save the printed address as `ATTESTATION_REGISTRY` in `.env` before deploying the hook.

<br/>

- Deploy Hook

```sh
source .env
forge script script/hook/DeployHook.s.sol:DeployHookScript --rpc-url "$RPC_URL" --private-key "$PRIVATE_KEY" --broadcast
```

output (sample):

```log
HOOK=<deployed hook address>
```

Save the printed address as `HOOK` in `.env`.


### Initialize Pool

```sh
source .env
forge script script/CreatePoolScript.s.sol:CreatePoolScript --rpc-url "$RPC_URL" --private-key "$PRIVATE_KEY" --gas-estimate-multiplier 600 --broadcast
```

Run this once for the configured token pair and hook. The script initializes a dynamic-fee pool with tick spacing `10` and a starting price of `1:1`.

<br/>

#### Transfer Token (Optional)

If another account needs test tokens, the token holder can run the transfer script. Set `RECEIVER` to the destination address; the script transfers `100` of each 18-decimal test token.

```sh
source .env
export RECEIVER="<receiver address>"
forge script script/Transfer.s.sol:TransferScript --rpc-url "$RPC_URL" --private-key "$PRIVATE_KEY" --broadcast
```

<br/>

#### Token Approve

Run this as the account that will supply liquidity or swap. It approves both tokens through Permit2 for the configured `POSITION_MANAGER` and `UNIVERSAL_ROUTER`.

```sh
source .env
forge script script/Approve.s.sol:DeployTokenScript --rpc-url "$RPC_URL" --private-key "$PRIVATE_KEY" --broadcast
```

#### Add Liquidity

The script sets a maximum of `1000` of each test token, uses ticks `-300` to `300`, and mints the liquidity position to `FEE_RECIPIENT`. Ensure the signer has enough tokens and has completed the approvals above.

```sh
source .env
forge script script/AddLiquidityScript.s.sol:AddLiquidityScript --rpc-url "$RPC_URL" --private-key "$PRIVATE_KEY" --broadcast
```

<br/>

#### Test Swap

After adding liquidity, this script swaps `1` test token from `TOKEN0` to `TOKEN1` through the configured universal router. Review the swap parameters in the script before running it.

```sh
source .env
forge script script/Swap.s.sol:Swap --rpc-url "$RPC_URL" --private-key "$PRIVATE_KEY" --broadcast
```
